# Umrah step pictograms

Original, faceless pictograms drawn in Figma for the six Umrah steps. They contain no text, so the same picture serves ar, en and ur; any caption comes from the reviewed step text.

Figma source: https://www.figma.com/design/eA3xHoDFN1yF8G1HoGmd8o (frames named `step/<step id>`).

| File | Step |
| --- | --- |
| umrah.ihram.svg | Ihram at the miqat |
| umrah.ihram-rules.svg | What is forbidden in ihram |
| umrah.tawaf.svg | Tawaf, seen from above, counterclockwise |
| umrah.tawaf-prayer.svg | Two rak'ahs behind the Maqam |
| umrah.sai.svg | Sa'i between Safa and Marwa |
| umrah.halq.svg | Halq (shaving) |

Not wired into the app yet. They are drawings from the Umrah steps, not copies of the booklet's images. The content reviewer should check each one against its step text (for example, the seven tally dots and the direction arrows) before they ship.
