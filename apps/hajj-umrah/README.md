# رفيق المناسك (Rafiq al-Manasik) — Hajj & Umrah Companion

Offline-first PWA that guides pilgrims step by step through Umrah and Hajj, in Arabic, English and Urdu.
Imported from the Figma Make file "Hajj Umrah Companion Design".

```bash
npm install
npm run dev      # local development
npm run build    # type-check and production build (service worker included)
npm run preview  # serve the build; the service worker only runs here, not in dev
```

## Content status

All ritual text in `src/App.tsx` is prototype copy and is **pending scholarly review**.
Ruling labels, instructions and supplications must be replaced by sourced, reviewed content before release.
